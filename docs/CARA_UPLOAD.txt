⭐ CARA KUSTOMISASI (HANYA 1 FILE!)
════════════════════════════════════════════════════════════════════════════════

Buka file:  js/config.js
Edit nilai-nilai berikut, lalu simpan (Ctrl+S) dan refresh browser:

  ┌─────────────────────────────────────────────────────────────┐
  │  Yang bisa diubah di config.js:                            │
  │                                                             │
  │  🏪 Identitas     → storeName, tagline, shortDescription   │
  │  📍 Lokasi        → locationCity, locationProvince          │
  │  📅 Operasional   → establishedYear, openingHours           │
  │  📞 Kontak        → whatsappNumber                          │
  │  🗺️ Peta          → mapCoordinates (lat/lng), mapZoom       │
  │  🔗 Sosial        → instagramLink, tiktokLink               │
  │  🚗 Pesan Online  → grabFoodLink, shopeeFoodLink            │
  │  📊 Statistik     → totalMenuItems, priceStartingFrom       │
  │  🔍 SEO           → metaTitle, metaDescription, metaKeywords│
  │  👤 Kredit        → ownerName, templateCreatorName          │
  └─────────────────────────────────────────────────────────────┘

CATATAN:
  • Jangan hapus tanda koma (,) di akhir setiap baris nilai
  • Jangan hapus tanda kurung kurawal { } atau [ ]
  • Isi field dengan "" (string kosong) jika ingin menonaktifkan link sosmed

📤 CARA UPLOAD
════════════════════════════════════════════════════════════════════════════════

CARA 1 — via FTP / cPanel File Manager:
  1. Buka cPanel → File Manager → public_html
  2. Upload seluruh folder dengan struktur yang sama
  3. Pastikan js/config.js juga ter-upload
  4. Akses: https://domain.com/index.html

CARA 2 — via GitHub Pages / Netlify / Vercel (GRATIS):
  1. Buat repository baru di GitHub
  2. Upload semua file ke repository
  3. Aktifkan GitHub Pages (Settings → Pages → Deploy from branch)
  4. Akses: https://username.github.io/nama-repo

CARA 3 — via Git CLI:
  git add .
  git commit -m "Setup template Mawar Coffee Shop"
  git push origin main
  → Deploy otomatis jika sudah terhubung ke Netlify/Vercel

📞 BANTUAN & TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Masalah: Nama toko tidak berubah setelah edit config.js
Solusi:
   • Pastikan file config.js ter-simpan (Ctrl+S)
   • Hard refresh browser: Ctrl+Shift+R
   • Pastikan tidak ada syntax error (buka F12 → Console)

Masalah: Gambar tidak muncul
Solusi:
   • Pastikan folder assets/images/ ter-upload lengkap
   • Periksa console browser (F12 → Console)

Masalah: Peta tidak muncul / lokasi salah
Solusi:
   • Cek nilai lat dan lng di CONFIG.mapCoordinates
   • Pastikan koneksi internet aktif (peta dari OpenStreetMap CDN)

Masalah: WhatsApp tidak terbuka atau salah nomor
Solusi:
   • Periksa CONFIG.whatsappNumber — pastikan format: "628xxxx" (tanpa +)

Masalah: Video hero tidak play
Solusi:
   • Video dihosting di Google Drive — pastikan link masih aktif
   • Coba di browser Chrome/Firefox versi terbaru
