## 🚀 CARA DOWNLOAD (3 Opsi)

### Opsi 1: Gunakan Script PowerShell (Windows)
```bash
# Jalankan dari terminal di folder project
./download-media.ps1
```

### Opsi 2: Gunakan Script Bash (Mac/Linux)
```bash
# Jalankan dari terminal di folder project
bash download-media.sh
```

### Opsi 3: Download Manual di Browser

1. **Untuk VIDEO**: 
   - Buka https://www.pexels.com/videos/
   - Cari: "coffee shop", "cafe", "barista"
   - Download dalam format MP4 (720p/1080p)
   - Simpan ke: `assets/images/hero-video-1.mp4` dst

2. **Untuk FOTO**:
   - Buka Pexels atau Unsplash
   - Cari keyword yang sesuai
   - Download format original atau WebP
   - Simpan ke: `assets/images/[nama-deskriptif].webp`

## 📝 Setelah Download - Update HTML

**JANGAN LUPA** mengganti src video di `index.html`:

**Dari:**
```html
<video autoplay loop muted playsinline class="hero-video active" id="hv0">
    <source src="https://drive.google.com/uc?export=download&id=...">
</video>
```

**Menjadi:**
```html
<video autoplay loop muted playsinline class="hero-video active" id="hv0">
    <source src="assets/images/hero-video-1.mp4" type="video/mp4">
</video>
```

Lakukan untuk semua 6 video (hv0-hv5).
